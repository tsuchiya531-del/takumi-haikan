# 現地見積り説明スクリプト

配管洗浄・詰まり抜き専門店 匠  
最終更新: 2026-04-14

---

## このスクリプトの使い方

- 各シーンの「台詞例」はそのまま読み上げる原稿ではない。自分の言葉に置き換えて構わない
- ただし【必須】マークがついた項目は、言い回しを変えても**必ず伝える**こと
- チェックリストは現場でスマホから確認できるよう、シーンごとに分けている

---

## シーン1: 到着〜ご挨拶（目安 2〜3分）

### チェックリスト

- [ ] 車両を邪魔にならない位置に停める（お客様に一声かける）
- [ ] 名刺を渡す
- [ ] 本日の作業の流れを3ステップで説明する
- [ ] 靴下カバー・養生シートを見せて「汚しません」を伝える
- [ ] 所要時間の目安を伝える

### 台詞例

**インターホン〜玄関**

> 「こんにちは。配管洗浄専門店 匠の〇〇です。本日はお問い合わせいただきありがとうございます。」

**名刺を渡しながら**

> 「本日の流れを先にお伝えしますね。まず症状を一緒に確認させていただいて、次にお見積りを出します。金額にご納得いただけたら作業に入ります。見積りの段階で"やっぱりやめます"でも構いません。費用はかかりません。」

【必須】**見積り前に作業しないことを明言する**

> 「お見積りを出す前に勝手に作業を始めることはありません。ご安心ください。」

**養生の準備を見せながら**

> 「作業中はこの養生シートと靴下カバーを使いますので、お部屋を汚す心配はありません。」

## シーン2: 症状確認・調査（目安 5〜10分）

### チェックリスト

- [ ] お客様と一緒に症状箇所を確認する（お客様を置き去りにしない）
- [ ] 症状の発生時期・頻度を聞く
- [ ] 過去に業者を呼んだことがあるか聞く
- [ ] 写真を撮る前に許可を取る
- [ ] 症状箇所の写真を撮影する（作業前の状態記録）
- [ ] 屋外の排水枡を確認する（戸建ての場合は必須）
- [ ] 調査結果をお客様にわかる言葉で説明する

### 台詞例

**症状箇所に案内してもらう**

> 「では、気になっている場所を見せていただけますか。一緒に確認しながら進めます。」

**状況を聞く**

> 「この症状はいつ頃から出ていますか？ 毎日ですか、それとも時々ですか？」

> 「以前、別の業者さんに来てもらったことはありますか？ もしあれば、その時の状況も教えていただけると助かります。」

**写真撮影の許可**

> 「症状の記録として写真を撮らせていただいてもよろしいですか。作業後の比較にも使います。」

【必須】**屋外排水枡の確認**

> 「戸建てのお宅は、屋外の排水枡が原因になっていることが結構あります。お庭のほうも確認させてください。」

**調査結果の説明（専門用語を使わない）**

> 「見させていただいた結果ですが、台所の排水管の中に油の固まりが溜まっています。これが水の通り道を狭くしているので、流れが悪くなっています。」

> 「屋外の枡も確認しましたが、こちらにも少し汚れが溜まっていました。今回はここも一緒にやったほうが再発しにくくなります。」

**原因を見せる（可能な場合）**

> 「こちらを見てください。（枡の蓋を開けて）この白い固まりが油脂です。これが配管の中にも同じように付いている状態です。」

## シーン3: 見積り提示（目安 3〜5分）

### チェックリスト

- [ ] 見積り金額を口頭で伝えた上で、書面またはタブレットでも見せる
- [ ] 作業内容と金額の内訳を説明する
- [ ] 追加費用が発生する可能性がある場合、その条件と上限額を事前に伝える
- [ ] お客様の反応を確認する（沈黙を急かさない）
- [ ] 断られた場合も丁寧に対応する

### 料金4プラン（参考）

| プラン | 内容 | 価格帯（税込） |
|---|---|---|
| 軽度 | 薬剤洗浄・手作業での詰まり除去 | 16,500〜27,500円 |
| 高圧洗浄 | 高圧洗浄機による配管洗浄 | 33,000〜55,000円 |
| 屋外排水管 | 屋外枡+排水管の高圧洗浄 | 44,000〜66,000円 |
| 匠コース | 写真記録・所見書・屋外枡確認・6ヶ月保証 | 66,000〜110,000円 |

### 台詞例

**金額を伝える**

> 「調査の結果、今回の症状には〇〇の作業が必要です。お見積りは税込〇〇円になります。」

**内訳の説明**

> 「内訳をご説明します。まず配管内の高圧洗浄が〇〇円、屋外の排水枡の洗浄が〇〇円です。出張費は含まれています。」

【必須】**追加費用の可能性がある場合**

> 「正直にお伝えすると、配管の中を開けてみたら予想以上に汚れがひどい場合があります。その場合は追加で〇〇の作業が必要になる可能性があります。追加になる場合の上限は〇〇円です。ただし、追加が必要になった時点で必ず作業を止めてご説明します。勝手に進めることはしません。」

【必須】**追加費用がない場合もその旨を明言する**

> 「今回のお見積り金額から追加になることはありません。この金額で全て完了します。」

**匠コースの提案（該当する場合）**

> 「今回の症状だと、再発の心配があります。匠コースですと、作業後に写真付きの所見書をお渡しして、6ヶ月の保証もつきます。万が一同じ症状が出た場合、無償で対応します。ご参考までにお見積りは〇〇円です。」

**お客様の判断を待つ**

> 「ご質問があれば何でも聞いてください。ご検討いただいて大丈夫です。」

**断られた場合**

> 「承知しました。出張・見積りの費用はかかりませんのでご安心ください。もし今後気になることがあれば、いつでもご連絡ください。本日はお時間いただきありがとうございました。」

※断られた場合に値引きで引き留めることは禁止。匠は値引きで売る店ではない。

## シーン4: 作業中（作業内容により 30分〜2時間）

### チェックリスト

- [ ] 作業開始を宣言する
- [ ] 養生を丁寧に行う（お客様が見ている前提で）
- [ ] 作業中、15〜20分に1回は途中経過を報告する
- [ ] 異常や想定外の状況が出た場合、即座に作業を止めてお客様に説明する
- [ ] 追加作業が必要な場合、口頭+書面で説明し、承諾を得てから再開する
- [ ] 作業音が大きい場合は事前に伝える

### 台詞例

**作業開始**

> 「それでは作業に入ります。大きな音が出る場合は事前にお声がけしますので、ご安心ください。」

**途中報告**

> 「〇〇さん、途中経過です。配管の中の汚れは順調に取れています。あと〇〇分ほどで完了の見込みです。」

> 「今こういう状態です。（スマホで撮った写真を見せながら）この黒い塊が詰まりの原因でした。これを取り除いている最中です。」

**想定外の状況が出た場合**

> 「〇〇さん、一度作業を止めてご報告があります。配管の中を確認したところ、〇〇の状態になっていました。このまま続けても問題ありませんが、〇〇の追加作業をすると再発防止になります。追加費用は〇〇円です。どうされますか？」

【必須】追加作業はお客様の承諾なしに絶対に行わない。

## シーン5: 作業完了〜お会計（目安 5〜10分）

### チェックリスト

- [ ] 作業結果をお客様と一緒に確認する（水を流して見せるなど）
- [ ] 作業前後の写真を比較して見せる
- [ ] 再発防止のアドバイスを具体的に伝える
- [ ] 最終金額を書面で提示する（見積りと差異がないことを確認）
- [ ] お支払い方法を案内する
- [ ] 養生を撤去し、周辺を清掃する

### 台詞例

**作業完了の報告**

> 「作業完了しました。一緒に確認していただけますか。」

**結果を見せる**

> 「水を流してみますね。（実際に水を流しながら）ご覧の通り、スムーズに流れています。作業前はここまで水が溜まっていましたが、今はすぐ引いていきます。」

> 「こちらが作業前の写真で、こちらが作業後です。配管の中の汚れがきれいに取れているのがわかりますか。」

**再発防止のアドバイス**

> 「再発を防ぐために2つだけお伝えさせてください。1つ目、台所では油をそのまま流さないこと。少量でも積み重なると配管の中で固まります。2つ目、月に1回でいいので、60度くらいのお湯をゆっくり流していただくと、油脂が溶けて流れやすくなります。」

> 「洗面台の場合は、髪の毛キャッチャーをつけていただくだけで、詰まりのリスクが大きく下がります。ホームセンターで200円くらいで売っています。」

**お会計**

> 「お見積りの通り、税込〇〇円です。お支払いは現金・カード・電子マネーに対応しています。」

【必須】**見積りと金額が変わっていないことを確認する一言**

> 「最初にお出しした見積り金額と同じです。追加はありません。」

## シーン6: 退出（目安 2〜3分）

### チェックリスト

- [ ] 何かあった場合の連絡先を伝える
- [ ] 保証がある場合はその内容と期間を再度伝える
- [ ] 定期メンテナンスの案内をする（押し売りにならないトーンで）
- [ ] 口コミ依頼は作業に満足いただけた場合のみ、さりげなく
- [ ] 忘れ物・片付け漏れがないか最終確認
- [ ] 玄関先で一礼して退出

### 台詞例

**アフターフォローの案内**

> 「本日の作業について何か気になることが出てきたら、遠慮なくご連絡ください。名刺に電話番号とLINEのQRコードが載っています。」

**保証がある場合（匠コース）**

> 「匠コースの6ヶ月保証がついていますので、万が一同じ症状が出た場合は無償で対応します。所見書は後日郵送しますので、保管をお願いします。」

**定期メンテナンスの案内**

> 「配管は目に見えない場所なので、年に1回くらいの点検をしていただくと安心です。もしご興味があれば、定期メンテナンスのご案内もできますので、お気軽にご連絡ください。」

※このタイミングでは案内のみ。その場で契約を迫らない。

**口コミ依頼（お客様が満足されている場合のみ）**

> 「もしよろしければ、今日の感想をGoogleの口コミに書いていただけると大変励みになります。こちらのQRコードから簡単に投稿できます。」

※お客様の反応が薄い場合、渋っている場合は即座に引く。「全然大丈夫です」と一言添えて終わる。

**退出**

> 「本日はありがとうございました。お困りのことがあればいつでもご連絡ください。失礼します。」

## 補足: 絶対に守る3原則（全シーン共通）

| 原則 | 具体的な行動 |
|---|---|
| 見積り後に作業 | シーン1で必ず口頭で宣言する。シーン3で見積りを出し、承諾を得てから着手する |
| 追加費用は事前説明 | シーン3で追加の可能性と上限額を伝える。シーン4で想定外が出たら即停止・説明・承諾 |
| 安さではなく安心 | 断られても値引きしない。再発防止や保証など「安心」の価値で提案する |

## 補足: やってはいけないこと一覧

- 見積り前に工具を出す、作業を始める
- 「今日やらないと大変なことになりますよ」など不安を煽る発言
- お客様が不在の間に勝手に作業範囲を広げる
- 追加費用を作業後に請求する
- 口コミを条件にした値引き・サービス提供
- 他社の悪口を言う
- 「うちは安いですよ」というアピール
