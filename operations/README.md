# 匠 運用ハンドブック

「機能する会社として毎日動き、日々進化していく」ための運用リズムと役員召集ルール。

---

## 3層の運用リズム

### 🌅 デイリー（5〜10分）
毎朝 or 毎晩に `operations/daily-log.md` を1ブロック追記。

- 問い合わせ件数・成約・広告数字の簡易チェック
- 未対応案件の確認
- 明日のタスク3つを決めるだけ

→ 数字異常があった時だけ役員召集（下の召集ルール参照）

### 📅 ウィークリー（30〜60分／毎週月曜推奨）
`operations/weekly-review.md` を1ブロック追記。

- **CMO**メイン召集：集客・CVR・広告パフォーマンス
- 検索語句レポートを見て除外KW・昇格KW決定
- 今週の学びを `knowledge/` 各ファイルに転記
- 来週の3大アクションを決める

### 📊 マンスリー（1〜2時間／月初3〜5日目）
`operations/monthly-review.md` を1ブロック追記。

- **取締役会（board-meeting）召集**：5人全員
- CFOの月次収支実績入力・予実対比
- CSOの競合動向レビュー
- 翌月の広告予算・施策計画
- 次月の最優先KPIを1つ決める

---

## 役員召集ルール

| きっかけ | 呼ぶ人 |
|---|---|
| 問い合わせ数が先週比 ±30%以上変動 | **CMO** |
| 広告CPA・粗利・キャッシュフロー関連 | **CFO** |
| クレーム発生・新サービス検討 | **CPO** |
| 競合の値下げ・新規出店・広告変化 | **CSO** |
| LP改修・計測バグ・自動化 | **CTO** |
| 複数観点が絡む重要判断／方針の岐路 | **取締役会（board-meeting）** |

召集時は必ず以下を添える（CLAUDE.md参照）:
- 議題
- 前提情報（関連ファイルパス、現フェーズ）
- 期待するアウトプット形式

## 毎日進化するコツ

1. **完璧を目指さない**：5分で埋めるだけでいい。書くことを習慣化する方が10倍大事
2. **数字と感触を両方残す**：数字だけだと現場の肌感が消え、感触だけだと判断がブレる
3. **役員に投げる前に読み返す**：過去ログを役員のプロンプトに貼ると、助言の質が段違いに上がる
4. **月1で必ず取締役会**：方向性の微修正を月1でかけることで「日々やってる作業の正しさ」を検証できる
