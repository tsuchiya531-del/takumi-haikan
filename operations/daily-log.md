# 匠 デイリーログ

毎朝 or 毎晩、5分で埋める。続けることが最優先。完璧を求めない。

## 書き方

各日付ブロックを上に追記（新しい日付が一番上）。
値が0件・変化なしなら「―」でOK。

---

## テンプレ（コピーして貼り付け）

```
### YYYY-MM-DD（曜日）

**数字**
- 問い合わせ: 電話X件 / LINEX件
- 成約: X件 / 平均単価 ¥XX,XXX
- 広告: 表示X / クリックX / 費用¥XXX / CV X
- 今日の残キャッシュ目安: ¥XXX,XXX

**案件メモ**（未対応・気になる案件だけ）
- 案件No XXX: 一言メモ

**今日の学び・気づき**（なければ空）
- 

**明日の優先タスク**（3つまで）
- [ ] 
- [ ] 
- [ ] 
```
